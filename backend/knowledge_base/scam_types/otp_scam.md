# Scam Type: OTP Scam

## Category
Authentication Scam

## Description
OTP scams attempt to steal one-time passwords to access victims' accounts.

## Common Keywords
- OTP
- Verification code
- Security code
- Login verification

## Common Indicators
- Requests OTP sharing
- Fake bank representatives
- Urgent account verification

## Prevention
- Never share OTP
- Banks will not request OTP
